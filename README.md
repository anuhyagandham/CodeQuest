# 🎮 CodeQuest – Gamified Coding Journey

## 📌 Project Overview
CodeQuest is a gamified coding platform developed using Python and Streamlit. It motivates users to improve their coding skills by completing missions, earning XP, unlocking achievements, participating in boss battles, and tracking progress through analytics.

## ❗ Problem Statement

Many beginners start learning programming with enthusiasm but gradually lose motivation due to a lack of consistency, progress tracking, and engaging learning experiences. Traditional coding platforms mainly focus on solving problems but often do not provide features that encourage continuous learning, reward achievements, or make the learning journey enjoyable. As a result, many learners struggle to stay consistent and eventually stop practicing.

## ✅ Solution

CodeQuest addresses this problem by transforming the coding journey into a gamified learning experience. The application motivates users through XP points, levels, daily missions, achievements, boss battles, skill progression, leaderboards, and analytics dashboards. It also integrates GitHub profile data using APIs to automatically display coding statistics, making learning more interactive, engaging, and rewarding.

## 🚀 Features
- 🏠 Dashboard
- 👤 User Profile
- 🎯 Daily Missions
- 👹 Boss Battles
- 🏅 Achievements
- 🌳 Skill Tree
