# 🎮 CodeQuest – Gamified Coding Journey

## 📌 Project Overview
CodeQuest is a gamified coding platform developed using Python and Streamlit. It motivates users to improve their coding skills by completing missions, earning XP, unlocking achievements, participating in boss battles, and tracking progress through analytics.

## 🚀 Features
- 🏠 Dashboard
- 👤 User Profile
- 🎯 Daily Missions
- 👹 Boss Battles
- 🏅 Achievements
- 🌳 Skill Tree
- 🏆 Leaderboard
- 📊 Analytics Dashboard
- ⚙️ Settings Page

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- JSON
